# Project Plan

This directory is the living planning record for **Project_1**, a learning
project for cloud development and version control.

## Files

- `roadmap.md` — milestones, scope, and planned order of work.
- `mvp.md` — the agreed application concept, user story, and first feature set.
- `progress.md` — dated implementation updates, checks, and blockers.
- `decisions.md` — significant technical decisions and why they were made.

Keep these files current as work happens. The repository-level `AGENTS.md`
defines the required update routine for every agent.
